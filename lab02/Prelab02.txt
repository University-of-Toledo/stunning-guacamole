Q1: What format specifier does printf use for a double and what does scanf use? Why do they differ?
	A: printf() uses %f to display a double
	Scanf() uses %lf to read a double.
	Printf() received floating point arguments by value, with float automatically promoted to double. Scanf() recieves pointers, so %lf tells it to expect a double, rather than a float.
	
Q2: Compute 7/2 and 7.0/2. Why are the different?
	A: In 7/2 =3 they are both ints, so the decimal goes away
	7.0/2=3.5 the 7.0 is a double so floating point division occurs.

Q3: What does scanf return when secussful? What if the first conversion fails?
	A: scanf() returns the number of input items successfully matched and assigned. Valid returns 1, Invalid returns 0
Q4: What happens when scanj("%d, &x) recieves abc?
	A: it would fail. You would have to use %c and separate 'a' 'b' and 'c' to get it to interpret aascii into numerical values.
	
Q5: Why should conversion functions use double instead of int?
	A: Its more consistent. Int will cut out all the decimals. 
	Celsius --> Fahrenheit	F=C*9/5 + 32	fahrenheit = celsius * 9.0 / 5.0 + 32;
	Miles --> Kilometer	Km=miles*1.609344	Kilometers = miles * 1.609344;
	Pounds --> Kilograms	Kg=lb*0.45359237	Kilograms = pounds * 0.45359237
